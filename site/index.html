    👩‍💻 Welcome to the DSA 1 Lab¶

    🧩 Course Overview¶

    Welcome to the Data Structures and Algorithms 1 (DSA 1) Lab.
    This website provides all your lab materials, including:

    • Step-by-step tutorials and lecture slides
    • Programming exercises and challenges
    • Sample solutions and best practices
    • Tools, setup, and submission instructions

    All labs are taught using the C programming language, focusing on:

    • Clear and structured problem-solving
    • Efficient coding practices
    • Understanding the link between algorithms and implementation

    🧭 How to Use This Site¶

    • Begin with Lab 1 and proceed in order.
    • Each lab section includes:
    • Concepts: core material, explanations, and code examples
    • Exercises: hands-on problems to implement
    • Assignments: GitHub Classroom submission links

    💡 You'll find a navigation sidebar on the left — use it to jump between labs and resources.

    🧰 Tools You'll Need¶

    Before starting, make sure you have:

    • GCC (Linux/macOS) or MinGW (Windows) compiler installed
    • A code editor — VS Code, Code::Blocks, or CLion are recommended
    • A GitHub account (for assignment submissions)

    👉 Check the Setup Guide if you haven't installed your environment yet.
    👉 Learn how to submit labs in the Git, GitHub, and Assignments Guide.

    📅 Lab Schedule¶

    Week Topic Focus

    🧑‍🏫 Submitting Your Work¶

    Assignments are managed through GitHub Classroom.
    Each lab includes a unique invitation link — accepting it automatically creates your private repository.

    🔒 Only you and the instructor have access to your submission.

    Once done:

    1. Push your code to your GitHub repo
    2. Verify your files are visible online
    3. Wait for your instructor's feedback

    💡 Tips for Success¶

    • Write clean, readable, and well-commented code.
    • Test frequently with different inputs.
    • Don't hesitate to experiment and debug — that's how you grow.
    • Ask questions during lab sessions and collaborate with peers.
